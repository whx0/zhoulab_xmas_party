# 🎁 Zhou Lab Xmas Party 2026

研究室クリスマスパーティーのクイズシステム。GitHub Pages ＋ Firebase Realtime Database だけで動く、ビルド不要の HTML/JS です。

- 参加者画面：`index.html`（スマホ）
- 管理者画面：`admin.html`（PC・スマホ。URLは参加者に教えない）

## 手元で試す（Firebase不要）

`js/config.js` の `apiKey` が空のままだと **ローカルお試しモード** で動きます。

```bash
python3 -m http.server 8000
```

`http://localhost:8000/admin.html` を1タブ、`http://localhost:8000/` を複数タブ（タブごとに別の参加者）。

## 本番のセットアップ

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクト作成（無料の Spark プランでOK）
2. 「Realtime Database」→ データベースを作成
3. 「ルール」に `database.rules.json` の中身を貼って公開
4. 「プロジェクトの設定 → マイアプリ → ウェブアプリを追加」→ 表示された設定を `js/config.js` に貼る（`databaseURL` も）
5. GitHub の Settings → Pages → Branch: `main` / `(root)` で公開
   - プライベートリポジトリで Pages を使うには GitHub Pro が必要（学生は Student Developer Pack で無料）

> ⚠ 簡単さ優先で、DB は誰でも読み書きできる設定です。正解などは参加者の画面には出ませんが、開発者ツールを使えば見られます。終わったら Realtime Database を削除してください。

## 当日の流れ

管理者画面の左メニューを **上から順に** 進めるだけです（スマホでは上部のタブ）。各ページに番号付きの手順と、押すボタンが表示されます。

- **準備（前日まで）**：問題リスト（形式・正解・制限時間・任意で選択肢の文字）→ R2 の素材（道具の画像・名前・点数、間違い探しの画像と正解位置）→ 配点・設定
- **本番**：受付（QRコード表示）→ 練習・R1 → チーム作り → R2 道具選び → R2 間違い探し → ペア作り → R3 プレゼントツリー → R4 一発逆転 → 結果発表
- **管理**：参加者・チーム・ペアの手動調整、得点の手動修正

参加者画面は 日本語 / EN / 中文 を切り替えられ、各ステージのルールが画面に表示されます。

テスト時は「配点・設定」で **テストモード** を ON にすると、参加者画面の下に「ログイン画面に戻る」ボタンが出ます（ローカルお試しモードでは常に表示）。
リハーサル後は「配点・設定 → 得点・回答・チーム・ペアだけ消す」。
